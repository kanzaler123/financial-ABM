## 本轮结构修正

1. 将基本面建模为带漂移的 Student-t GARCH 创新，固定种子后可精确重放。
2. 公开基本面冲击先形成参考价格，Agent 超额需求只形成剩余价格偏离，避免重复计价。
3. 价值型和趋势型 Agent 使用不同风险敏感度、趋势观察期和个体决策噪声。
4. Logit 每 60 日只异步更新 15% Agent，取消全市场同时换策略。
5. 允许受 0.25 倍杠杆约束的有限卖空，使价值投资者能够纠正高估。
6. 多路径校准使用共同市场因子和行业特有冲击，同时评估时间序列与横截面。

## 核心修正

1. 默认基本面改为透明 Gaussian 信息过程，Student-t/GARCH-t 降为外生压力对照。
2. `public_news_price_pass_through=0`，公告和基本面变化必须经过 Agent 下单与净需求形成价格。
3. 增加异步参与、波动响应参与和策略内共同信念，作用对象是订单行为而不是收益序列。
4. 流动性压力和初始财富集中均作为可关闭机制，分别与固定流动性、均等财富基线比较。
5. value-only、trend-only、noise-only、无 Logit、独立信号和固定参与等消融均写入统一协议。

## 机制归因

- value-only 的价格偏离显著小于 noise-only，价值策略承担价格锚作用。
- trend-only 的收益持续性高于 noise-only，趋势机制方向正确。
- 关闭 Logit 后策略换手精确为零；完整市场的策略构成随适应度变化。
- 关闭共同信念后收益可预测性明显升高，共同下单与异步参与共同改变市场状态。
- 开启流动性压力后绝对收益自相关和峰度上升；该情景中的截断被明确记录，
  不冒充完整市场结果。
- GARCH-t 只标记为外生对照，不作为 Agent 内生生成厚尾的证据。
