## 2. v13 机制（相对 v6 的四项重设计）

1. **对称自归一化深度响应**：深度 = base × exp(−sens × stress)，stress 由
   快速 EWMA 波动率相对慢速 EWMA 参考（`volatility_reference_decay=0.99`）
   归一化。取代了 v6 的单侧地板制度，跨种子波动率水平不再导致"平静种子
   不触发、热种子爆炸"的双峰行为。
2. **参考财富锚定的订单规模**：头寸目标与订单规模锚定初始股权
   （`reference_wealth`），消除财富随机游走水平注入订单流的长记忆。
3. **相关噪声需求**：`common_signal_correlation=0.55` + 更高特质噪声与
   波动缩放（idio 0.30、ns 1.2、指数 1.15）——需求流产生净失衡，
   厚尾中位数从 v6 的 0.25 提升到 ~1–2（部分种子 5–8，接近经验 6.5–10.7）。
4. **水平稳健性**：`public_news_price_pass_through=0.95`（消除 2500 日
   尺度上未修正新闻成分的累积性价格偏离）、价格上限 0.30、深度地板 0.40。

以及正式验收暴露并修复的三个结算边界 bug：Gini 浮点擦除、保证金下限的
新闻垫底（4σ）、**强平豁免做市商现金配给**（此前的按比例配给会同时削减
强平单，导致头寸跌破杠杆下限）。

## 3. 正式验收（v13）剩余差距：长周期稳定性

50 正式种子 × 1000 日 burn-in + 2500 日统计期的四项未过门槛：

| 门槛 | 通过率 | 说明 |
| --- | ---: | --- |
| `full_runs_without_price_cap` | 0/1 事件 | 125000 个交易日内出现极端日 |
| `full_heavier_than_gaussian` | 70% | 2500 日样本上 15/50 种子峰度 < 0.1 |
| `full_volatility_clustering_has_decay` | 74% | 13/50 种子（ACF20 平台或 ACF1/5 偏弱） |
| `endogenous_liquidity_feedback_increases_tail_weight` | 74% | 13/50 种子差值 < 0.05 |

价格发现在长周期上已基本修复（通过率 0.42 → 0.86，波动率 1.0，量价 0.9）。
剩余问题全部集中在**长周期样本上的尾部与聚集稳定性**：1000 日评估的
dev/holdout 协议无法暴露这些 2500 日尺度的问题，正式协议是目前唯一能
观测它们的仪器——这正是它存在的意义。
