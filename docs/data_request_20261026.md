# 数据导出清单（2026-10-26，按平台、库、表、字段写）

对应[长期计划](plan_20261026.md)第 3 节。表名和字段代码中，标了（已核实）的来自 CSMAR 使用指南或公开的数据说明；其余以平台显示的中文字段名为准，勾中文名即可。找不到的项先跳过，把名称相近的表截图给我。

## 通用设置

- **CSMAR**：代码选择「全部股票」，**包括已退市公司**；格式选 CSV（或 Excel）；勾选「下载字段说明」（会多一个 `[DES]` 文件）；时间按下面每项填写。一次导出行数受限时按年份分几次。
- **存放**：每个平台一个文件夹，例如 `data/raw/csmar_20261027/`、`data/raw/wind_20261027/`，保留原始文件名，不要改动内容。已在 `.gitignore` 中，不会提交。
- 每个文件夹里放一个 `说明.txt`：导出日期、平台、库名和表名。

## 第一批

### ① 华证 ESG 评级——Wind（CSMAR 里没有）

- **在哪里**：Wind 终端或 Excel 插件，指标搜索「华证 ESG」。同花顺 iFinD、Choice 也有，用哪个都行。
- **指标**：综合评级、综合得分、E 评级与得分、S 评级与得分、G 评级与得分，以及评级日期。
- **范围**：全部 A 股（含已退市）；季度；2009 年一季度至最新。导不了全部历史时，至少导 **2020 年第四季度**这一期的全部公司。
- **务必记下导出日期**：华证会按新方法追溯调整历史评级，不同时间导出的历史可能不同。
- **用途**：与网盘面板逐条核对（阶段 H1）；如果是全部历史，就直接替换网盘数据。

### ② 财务报表——CSMAR「公司研究系列 → 财务报表」

- **资产负债表 `FS_Combas`**、**利润表 `FS_Comins`**。
- **筛选**：报表类型选「A 合并报表」；会计期间只要每年 12-31（年报）；2008–2025。
- **资产负债表字段**：证券代码、会计期间、报表类型、资产总计、短期借款（`A002101000`，已核实）、一年内到期的非流动负债、长期借款（`A002201000`，已核实）、应付债券、负债合计、所有者权益合计、归属于母公司所有者权益合计。
- **利润表字段**：营业收入、财务费用（`B001211000`，已核实）、其中：利息费用（`B001211101`，已核实）、其中：利息收入、利润总额、净利润。
- **补充**：「其中：利息费用」这一行 2018 年起才进入利润表格式，之前大多为空。所以另导「财务报表附注 → 财务费用」明细表（`FN_Fn051`），2008–2017，全部字段。
- **用途**：债务成本 = 利息费用 ÷ 平均有息负债，再对华证得分回归，得到本样本的 ESG 融资溢价（阶段 I）。

### ③ 月度股票交易——CSMAR「股票市场系列 → 股票市场交易 → 月个股回报率文件 `TRD_Mnth`」

- **字段**（已核实）：`Stkcd` 证券代码、`Trdmnt` 交易月份、`Mclsprc` 月收盘价、`Mretwd` 考虑现金红利再投资的月个股回报率、`Msmvosd` 月个股流通市值、`Msmvttl` 月个股总市值、`Markettype` 市场类型。
- **范围**：2009-01 至最新；市场类型选上证 A 股、深证 A 股、创业板、科创板。市值单位是千元。
- **用途**：公司规模、评级变化后的股价反应（阶段 J）。

### ④ 公司基本信息——CSMAR 两张表

- **公司文件 `TRD_Co`**（股票市场交易库内）：全部字段即可，主要用证券代码、上市日期、行业代码（证监会 2012 版）、公司状态及状态变更日期（用来识别退市）。
- **股权性质 `EN_EquityNatureAll`**（公司研究系列）：字段（已核实）`Symbol`、`EndDate`、`EquityNature` 股权性质（国企、民营、外资、其他）、`EquityNatureID`、`ActualControllerNatureID` 实际控制人性质编码；2008–2025 年度。
- **用途**：行业、上市年限、国企与民企的分组与控制变量。

### ⑤ 违规处理——CSMAR「公司研究系列 → 违规处理 → 违规信息总表 `STK_Violation_Main`」

- **字段**：全部勾选（约 22 个），包括公告日期、违规年度、违规类型及编码、违规行为、处理单位、违反的法律法规、处分措施、罚款金额。
- **范围**：公告日期 2009-01-01 至最新。
- 库里如果还有「处罚对象」之类的子表，也一并导出。
- **用途**：信息披露违规每年被查处的比例与罚款分布，替换模型中假设的每期 1% 核查概率和按法条上限设定的罚款（阶段 K1）；2020 年《证券法》提高罚款前后的对比（阶段 M）。

## 最低限度

只能导一部分时，按这个顺序：**② → ③ → ④ → ⑤**，有 Wind 再加 **①**。这四项决定了阶段 I（融资溢价）和阶段 K1（执法强度）能不能做。
