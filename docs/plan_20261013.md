# 计划：从“拟真市场”转向“多智能体演化”（2026-10-13）

## 0. 为什么要调整

申请书的核心是**双主体演化**：投资者在利润导向（PM）和影响力导向（II）之间相互模仿，企业在“真实改善 / 漂绿 / 维持”之间博弈，再融入强化学习；最终产出三项结果——信息型与惩罚型政策的比较、相图（转型成功 / 失败 / 漂绿陷阱）、规模鸿沟。

此前的工作主要在打磨“市场像不像真的”：守恒、厚尾、价格截断、逐位重放、数据校准。这些是必要的地基，但已经够用了。继续打磨市场的边际收益很低，而智能体层还有大量工作没有开展。本计划把重心转向智能体，市场只修 bug，不再调优。

## 1. 智能体现状

| 智能体 | 申请书设想 | 现状 |
|---|---|---|
| 投资者 PM / II | 均值—方差加偏好 λ、softmax 配置、耐心异质、按季度模仿 | 已实现。**疑点**：零偏好对照中，II 与 PM 行为完全相同，但 3 个种子里 II 占比都上升（0.19→0.32、0.25→0.37、0.29→0.49），幅度与有偏好时相近。模仿可能主要是噪声漂移，而不是“选择优胜者” |
| 企业（NPV） | 真实改善 / 漂绿 / 维持，三选一 | 已实现。当前参数下从不漂绿，原因已经查明：罚款被设成了现实的约 50 倍，见[诊断](../reports/disclosure_wash_diagnosis_20261012/README.md) |
| 企业（强化学习） | “融入 AI 强化学习的演进模式” | 表格 Q-learning 已实现，但训练覆盖始终不达标，没有用于任何结论 |
| 遗传算法 | 申请书提到 | 未实现 |
| 监管者 | 外生政策冲击 | 只有外生的政策时间表，监管者不会根据情况调整 |
| 评级机构 / 鉴证方 | 未提 | 无 |

## 1.5 博弈论如何接入（2026-10-13 补充）

模型本身就是多智能体系统：1000 名投资者、200 家企业，加上监管者。博弈论可以给每一层智能体提供一个**解析基准**，仿真则检验有限理性、会学习的智能体能否到达这个均衡，以及在哪里会偏离均衡、陷入陷阱。这比单纯跑仿真更有研究价值，也更容易向读者讲清楚。

| 层面 | 对应的博弈 | 解析基准 | 仿真检验什么 |
|---|---|---|---|
| 企业与监管者 | 检查博弈（inspection game） | 定额罚款相当于固定成本，可以推出漂绿的闭式条件；透明度门槛 τ* = 1 − √w·A_r/A_w | NPV 企业是否满足这些条件；加入市场反馈后条件是否仍成立 |
| 企业与投资者 | 信号博弈 | 混同均衡（所有企业都美化披露，投资者无法区分）与分离均衡（只有真实改善的企业报告高分） | 相图中的“漂绿陷阱”是否就是混同均衡；透明度、核查、鉴证能否把市场推向分离均衡 |
| 企业之间 | 争夺影响力资本的竞争 | softmax 配置让影响力资本流向相对 ESG 更高的企业，一家改善会降低其他企业的相对吸引力，可能出现“军备竞赛”或搭便车 | 学习型企业之间会形成什么样的策略格局 |
| 投资者群体 | 演化博弈（复制动态） | 两类收益相等时占比不应变化；收益不等时存在稳定的共存比例（ESS） | 用复制动态的预测诊断现在的模仿机制，直接对应阶段 C |
| 监管者 | 斯塔克伯格博弈（监管者先承诺政策） | 定向核查是对企业漂绿倾向的最优反应 | 随机核查与定向核查的比较，对应阶段 E 第 1 项 |

落到各阶段：阶段 B 写出检查博弈的两个命题；阶段 C 以复制动态为基准；阶段 D 检验学习型企业是否收敛到最优反应；阶段 E 把监管者做成策略性参与者；阶段 F 的相图按“分离 / 混同 / 转型失败”分类。

## 2. 阶段安排

每个阶段都要通过验收才进入下一个阶段。工作量用“小 / 中 / 大”粗略表示。

### 阶段 A：收束（小）

- 整理仓库并分批提交：代码、测试、配置、精简后的报告进 git；原始数据、采集结果和大体积 npz 通过 `.gitignore` 排除，只保留重建脚本和 hash 清单。
- 把三项设定写进研究契约：罚金 = 监管罚款；罚款改为有上限的定额，按比例罚作为对照；融资溢价以“每 SD 约 28 个基点”为校准目标。
- 市场层冻结：把已知缺陷写明（3 个机械 FAIL、预热期截断、种子 23002 的价格截断），之后只修 bug。

验收：全量测试通过；`git status` 中不再有原始数据；研究契约新增一节。

### 阶段 B：让企业的博弈真正发生（中）

1. 实现定额罚款。法定罚款是一笔固定金额，在企业决策里相当于固定成本，所以漂绿会变成“做或不做”的离散选择。保留原来的比例罚作为对照，补测试。
2. 校准投资者偏好强度：用模型已有的定价斜率诊断，对准“每 SD 约 28 个基点”的融资溢价。这是对经验目标的校准，不看政策结果。
3. 用插桩诊断确认三件事：漂绿确实会发生；罚款占市值的比例随规模下降，因此大公司更倾向于漂绿；透明度门槛附近有合理的过渡。

验收：开发网格中出现非零漂绿，并且信息型、惩罚型政策的对比不再机械地为 0；如果仍然为 0，就停下来报告原因，不调参凑结果。

**状态（2026-10-13）：通过验收。** 见[阶段 B 报告](../reports/disclosure_fixed_fine_diagnosis_20261013/README.md)、[两个命题](disclosure_inspection_propositions.md)和研究契约第 16 节。偏好强度按政策前股息率斜率校准为 `taste_median = 0.0635`。报告第 4 节列出四个待决定的问题：评分天花板、罚款记账方式、比例罚对照的量级、成本随真实水平下降。评分天花板已按研究契约第 17 节实现为评分饱和，并重跑了开发网格，见[第二版](../reports/disclosure_saturation_diagnosis_20261013/README.md)：漂绿决策占比从 51% 降到 33%，验收条件仍然满足。

### 阶段 C：让投资者演化可信（中）

1. 诊断模仿机制：区分“选择”（II 因为表现更好而扩张）和“漂移”（噪声或机制偏差导致的占比变化）。做法包括：零偏好时的占比变化分布（多种子）、增长率差异的信噪比、群体规模不对称是否造成系统性偏差。
2. 如果确实以漂移为主，就按申请书原意修正，例如使用更长的业绩评估窗口、风险调整后的收益、加入切换成本；并把“市场自身的转型动力有多大”这个问题的答案如实写出来，即使答案是“很小”。

验收：零偏好对照中 II 占比没有系统性变化（多种子区间包含 0）；有偏好时的变化可以与之区分。

**状态（2026-10-13）：通过验收。** 见[阶段 C 报告](../reports/disclosure_imitation_diagnosis_20261013/README.md)和研究契约第 18 节。原规则缺少随机抽取比较对象这一步，零偏好时的上升主要来自规模不对称偏差；按 Schlag 原意修正后，零偏好时没有漂移，偏好带来的扩张约为每 14 年 2–3 个百分点。主设定改用修正规则，偏好强度重新校准为 0.0724。

### 阶段 D：强化学习企业（中到大）

1. 诊断 Q-learning 覆盖不达标的原因：状态空间是否过大、训练世界是否不足、奖励是否太稀疏。必要时缩小状态空间。
2. 在同一网格上对比 NPV 企业与学习型企业，检查政策排序是否一致（申请书 M4）。
3. 研究问题：有限理性的学习型企业，会不会在 NPV 认为不划算的区域里“学会”漂绿，从而形成漂绿陷阱？这是强化学习在本项目中最有研究价值的用途。

验收：训练覆盖达到预先设定的门槛；两种企业的比较结果写入报告，无论排序是否一致。

**状态（2026-10-14）：未通过验收。** 比较结果已写入报告，但覆盖门槛没有达到。
- [D.1 诊断](../reports/disclosure_rl_diagnosis_20261013/README.md)：根本原因是信号太弱。最优动作只比“维持”多约 0.07 个基点市值，而奖励噪声约为每期 2 个基点；每个状态—动作格需要 10⁶–10⁸ 个样本才能学会。
- [D.2 比较](../reports/disclosure_rl_comparison_20261013/README.md)：按研究契约第 19 节修复了可修复的部分（7 个动作、契约规模训练、递减步长、自身评分三分位状态、单期资源预算）。修复后未访问状态约为 0，但政策后大企业组的计数仍不足。
- 学习型企业与 NPV 企业的 I − F 符号一致，场景排序不一致（学习型企业在 F 下比 B 更差）。但同一环境下两张独立训练的表，漂绿占比分别约 69% 和 15%，所以学习型企业的排序无法与训练随机性区分。
- 学习型企业不进入阶段 F 的主实验。如果仍要研究“有限理性企业陷入漂绿”，需要每个场景多次独立训练，并做一个“状态能看到在途改善”的对照，见 D.2 报告第 8 节。

**D.3 重做（2026-10-23）：覆盖仍未全部通过，阶段 D 验收仍未满足。** 见[D.3 报告](../reports/disclosure_learning_redo_20261021/README.md)和研究契约第 23 节（确认性，运行前预注册，每个场景 10 次独立训练，并加“看得见累计改善”的对照状态）。
- 覆盖：按预注册的决策加权门槛，91/100 张表通过；未通过的 9 张都是政策后表，大多卡在大企业组。
- 训练随机性占主导：同一场景内各表的漂绿占比从 15% 到 83% 不等，表间标准差是表内的 14–18 倍。
- 漂绿陷阱（P1 supported）：信息政策下，学习型企业漂绿 23.7%，离散 NPV 为 3.8%；其中约三分之二是 NPV 不会做的，占全部决策的 15.5%。这些决策的损失中位数只有 0.042 个基点，是学不出来的陷阱，不是学到了漂绿有利可图。
- 看得见改善：主要问题 unresolved；辅助分析中，政策前表的漂绿占比降低 35 个百分点，但减少的漂绿变成了维持，真实改善没有增加。
- 政策反应：信息政策 +0.16 SD（Holm 后 unresolved），惩罚政策约为 0。I − F 符号与 NPV 一致。学习型企业仍不进入阶段 F 主实验。

### 阶段 E：新智能体（按价值排序，可选）

1. **基于风险的监管者**（推荐）：核查不再随机，而是针对披露突然跳升、或与同行偏离较大的公司。这对应证监会实际采用的风险导向监管，可以比较“随机核查”与“定向核查”。
2. **鉴证方 / 评级机构**：第三方鉴证降低披露噪声；多家评级机构给出不同评分，从而产生评级分歧，可以和现实数据对照。
3. **遗传算法**：让企业策略参数在群体中演化，作为强化学习的对照（申请书提到过）。
4. **LLM 智能体**（探索与展示用）：例如由 LLM 扮演企业撰写可持续发展报告，再由另一个 LLM 或检测器评分，展示文本层面的漂绿。它在 X 和 GitHub 上很吸引眼球，但成本高、难以复现、研究效度低，只适合作为少量智能体的演示模块，不进入核心结论。

**第 1 项状态（2026-10-20）：完成。** 见[定向核查报告](../reports/disclosure_targeted_audits_20261020/README.md)和研究契约第 21 节（确认性，新种子 42001–42030，五个主要问题都 supported）。在核查次数相同、企业知道规则时，按市值和按跳升两条定向规则的等权真实变化都差于随机核查（−0.19 与 −0.14 SD）：按市值把漂绿从大企业挤到小企业，按跳升被企业压在门槛下规避；规则不公布时与随机核查没有可分辨的差别。信息政策仍优于“按市值定向 + 4 倍罚款”。

**第 2 项状态（2026-10-21）：鉴证方部分完成，评级分歧未做。** 见[鉴证机构报告](../reports/disclosure_assurance_20261021/README.md)和研究契约第 22 节（确认性，新种子 43001–43030，五个主要问题都 supported）。16 倍法定上限的责任、随机指派鉴证方时，等权真实变化 +0.27 SD；让企业挑选鉴证方时，漂绿集中到当年最松的鉴证方，效果减少约 0.20；法定责任（1 倍）下鉴证质量约 0.014，效果小（+0.05）。只强制大企业时漂绿外溢到中小企业。信息政策仍略优于最强的鉴证。

### 阶段 F：核心实验（大）

研究设计在运行之前写进配置并冻结，按契约规模（1000 名投资者、200 家公司、3500 天）运行，使用新种子：

1. 信息型 vs 惩罚型：在相同期望罚金下比较，并给出剂量—反应曲线；同时比较定额罚与比例罚。
2. 相图：横纵轴分别为 λ 均值和初始 II 占比，以及漂绿成本比例 w 和透明度 τ；把每个区域分类为转型成功、失败或漂绿陷阱。
3. 规模鸿沟：比较大、中、小企业的真实改善和漂绿差异。
4. 稳健性：NPV 企业与学习型企业对比；主设定与两个初始化对照。

**状态（2026-10-15）：完成。** 见[阶段 F 报告](../reports/disclosure_stage_f_20261014/README.md)和研究契约第 20 节（运行前提交，`2b08f65`）。59 个场景 × 30 个种子，企业为 NPV 规则；学习型企业未通过阶段 D，没有纳入。
- **主要问题：** 四个都得到支持。市场偏好使全期真实水平 +0.79 SD；在指定剂量下信息政策优于惩罚政策（I − F +0.21 SD）；政策只能通过市场偏好起作用；规模差距来自大企业漂绿，而不是成本。
- **解析预测：** 透明度门槛 τ*(w) 对是否漂绿的预测在 16 格上全部成立。
- **与计划的差异：** 第 1 项“在相同期望罚金下比较”没有实现。实际比较的是事先固定的剂量（透明度 0.6 对定额罚款 4 倍）和各自的剂量梯度，没有按期望罚金或实施成本匹配，所以结论是这些剂量下的排序。
- **其他结果：** 定额罚款的边际威慑递减；在等额参照下，比例罚弱于定额罚，并使规模关系翻转（大企业的漂绿占比低于小企业），但没有消除漂绿本身（比例罚 1× 下大企业仍有 72%）。
- **限制：** 政策效应的量级依赖未经校准的自然衰减。按契约第 20.14 条，量级以统一衰减 0 到 0.2 SD/年的区间报告，例如 I − B 为 +0.04 到 +0.33 SD；排序在两端都成立。
- **后续：** 衰减形式待经过核实的评级面板确定（阶段 H）；如果数据支持向均值回归，再做阶段 F 第二版。阶段 G 可以先开始，并在沙盘中把衰减做成可调参数。
