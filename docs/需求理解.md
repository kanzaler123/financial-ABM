- 完成 Kenneth French 49 行业日频组合的基准统计流程，才满足进入下一阶段的统计门槛。

PySide6 原生动态监控与回放工具。当前实现尚无进程安全遥测队列、
三种运行模式、播放控制、DuckDB/Parquet 回放和相关一致性测试，
因此不能称为“第一阶段完成”。

# 最终目标确认：结构生成真实性，而非历史拟合

## 核心目标

本项目的最终目标是建立一个机制忠实的人工金融市场，使市场参与者、交易、价格发现、
流动性、信息、学习、约束和企业行为之间的因果渠道与真实金融市场相对应，并能够从这些
机制的相互作用中内生地产生真实市场常见现象。

项目不要求拟合某一段历史股市路径，也不以预测 Kenneth French 49 行业未来收益为目标。
真实数据用于检查数量级、方向和风格事实是否合理，不用于要求模型复刻既有价格序列。

## 目标现象

在不直接硬编码目标统计的前提下，模型应能够在适当条件下产生或解释：

- 价格发现与基本面偏离；
- 趋势、反转、泡沫和崩盘；
- 厚尾、波动聚集和状态切换；
- 成交量—波动关系；
- 流动性变化、卖空/融资约束和反馈；
- 信息不对称、传播延迟、信任与羊群行为；
- 策略适应、财富再分配和市场生态变化；
- 企业公告、真实行动和资本市场反馈。

这些现象不是要求每次运行全部出现，而是要求在对应机制和情景被启用时能够稳定出现，
并在关闭该机制的消融实验中减弱或消失。

## “机制一模一样”的工程解释

真实金融市场无法在有限 ABM 中逐项复制所有交易所、券商、清算、法规、订单簿和主体。
本项目采用“因果机制忠实”作为可实现标准：

- 参与者能看到什么信息、何时看到，必须真实；
- 决策、订单、成交、价格和结算的因果顺序必须真实；
- 现金、持仓、融资、卖空和流动性约束必须有明确对应；
- 市场现象必须来自这些机制，而不是为了命中统计而直接写入；
- 被简化的微观结构必须明确标注，并能在需要时替换。

当前 plan 使用日频同步市场和做市商净需求价格冲击，并明确排除连续订单簿。因此它追求的
是日频因果机制忠实，不是逐笔交易层面的微观结构完全相同。如果要求交易所级机制一致，
则必须把连续限价订单簿、订单优先级、撤单、保证金、借券、清算和日内时钟重新纳入 plan。

## 数据与测试原则

1. 核心基准使用简单、透明的外生信息过程，避免预先注入待解释现象。
2. Student-t、GARCH 和共同因子只能作为对照模型、压力情景或明确的外生机制，不能用来
   冒充 Agent 交互产生的厚尾和波动聚集。
3. Kenneth French 49 等真实数据用于风格事实和数量级检查，不用于历史路径拟合。
4. 每个目标现象都必须有机制开启、机制关闭和替代基线三组实验。
5. 验收关注现象能否由正确机制生成、方向是否正确、跨种子是否稳定，而不是逐项命中
   某段历史统计的四分位区间。

## 当前代码调整方向

- 将 Student-t GARCH 与共同市场因子从默认核心基准降级为可关闭的外生冲击插件/对照。
- 默认阶段 1 使用透明的基础信息过程，重新检验厚尾、波动聚集等现象是否由 Agent 互动
  内生出现。
- 保留有限卖空、异质策略和异步 Logit，但通过机制测试确认其现实含义和因果方向。
- 为价格发现、泡沫/崩盘、波动聚集、成交量—波动关系和策略生态分别建立消融测试。
- 在机制归因完成前，不用历史拟合结果宣告阶段完成。

# 项目目标与阶段 1 验收逻辑纠正

## 需求概述

本项目不是以复刻 Kenneth French 49 行业收益分布为最终目的的收益率生成器，也不是价格
预测或自动交易系统。它是一个日频、可审计、可重放、支持机制开关与反事实比较的人工
金融市场实验平台。

最终用途是在同一个受控 Harness、信息时钟和结算环境中，逐层加入并隔离比较：

- 投资者规则策略与策略模仿；
- 信息图、传播延迟、来源和信任；
- Bandit/Q-learning 等适应性决策；
- 企业行动、真实公告和通用 Factor Plugin。

研究者需要回答的是“加入某个机制后，价格发现、波动、成交、持仓、奖励和企业行为为何
发生变化”，而不是“能否把七个收益统计量逐项拟合进某个行业分布区间”。

当前三阶段 plan 是唯一范围依据。`docs/方案设计.md` 中旧的 Stage 0–6 和 LLM 主线已经
被当前 plan 的“LLM 不进入主线”决定取代。

## 阶段 1 的正确角色

阶段 1 是后续图、学习和真实因子实验的可识别基准与零模型。它必须证明：

1. 市场状态、事件时序、交易和结算是正确且可复现的；
2. 价值、趋势、噪声和 Logit 模仿按定义工作，开关机制能恢复对应基准；
3. 市场不会爆炸、机械撞限、资源耗尽或退化为无交易；
4. 生成的收益统计在真实市场的合理数量级内，不是明显退化过程；
5. 每个统计特征的来源可以通过消融实验解释，为后续阶段保留可测增量。

Kenneth French 49 数据在阶段 1 中用于尺度校准、退化诊断和风格事实合理性检查，不应被
当作要求模型逐项复刻的预测测试集。尤其不能为了命中厚尾和波动聚集而直接把这些特征
硬编码进外生过程，否则后续无法识别 Agent 交互、信息图或学习机制的真实增量。

## P0 验收标准

### 引擎有效性

- 固定配置和随机种子精确重放；
- 现金、持仓、库存和交易成本逐日对账；
- 无重复结算、未来信息泄漏和非法状态；
- 可视化、队列和回放不修改市场结果。

### 机制有效性

- 基本面上升时价值策略净需求方向正确；
- 持续价格趋势出现时趋势策略净需求方向正确；
- 噪声策略长期均值接近零且不同 Agent 不同步；
- 更高策略适应度产生更高 Logit 选择概率；
- 关闭 Logit、某类策略或公告后精确恢复相应消融基准。

### 系统行为

- 1000 个 Agent × 250 日在多种子下无爆炸和机械价格截断；
- 交易量、价格偏离和策略占比不因现金或持仓耗尽而退化；
- 收益波动率处于真实日频市场的合理数量级；
- 收益自相关接近零、绝对收益自相关为正、峰度为正；
- 上述范围只用训练数据预注册，并报告置信区间和种子稳定性，不使用简单 7/7 IQR
  作为科学有效性的唯一判据。

### 因果可识别性

- 分别运行 value-only、trend-only、noise-only、无 Logit 和完整模型；
- 记录各机制对波动率、自相关、厚尾、成交量和价格偏离的增量；
- 若某个特征主要来自外生 Student-t/GARCH，而非 Agent 机制，必须明确标注；
- 阶段 2 只能在阶段 1 的机制来源可以解释后开始。

## 当前结果的重新定位

已生成的 29/10/10 和封存测试报告保留为探索性统计诊断，不再单独决定阶段 1 是否完成。
`FAIL_SEALED_TEST` 只表示未通过此前临时定义的 7/7 IQR 规则，不等于项目目标上的最终
失败。

当前代码中新增的 Student-t GARCH、公开基本面直接重定价、共同市场因子和有限卖空需要
逐项消融，判断它们是必要市场机制、压力测试配置，还是为了拟合统计而造成的范围漂移。
完成该机制归因前，不进入阶段 2。
