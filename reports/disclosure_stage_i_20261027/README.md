## 结论

1. **本样本的融资溢价约为模型原有融资激励的 12.6 倍。** E1：华证得分每高 1 SD，次年债务成本低 28.0 个基点 [23.4, 32.5]；这是关联，不是因果效应。加公司固定效应后为 11.9 [7.4, 16.4]。模型中企业决策所用的融资利率局部反应，在 Q 下、现行利差 s₀ = 0.05 时为 2.21 个基点（第 26.16 条）。
2. **只调利差（v1）不可行。** 让利率反应对准 π̂ 需要 s* = 0.6057，这时初始合同利率已是 22.7%。开发运行中 s* 下 42 个运行有 37 个失败，其中 36 个是因为融资调整耗尽了价值锚，1 个是价格与内在价值发散。没有冻结，也没有正式运行（第 26.19 条）。
3. **方案 A：债务利率直接对公开评级作出反应。** λ* = 25.75 个基点/单位信号，政策前 ρ_total 的中位数为 28.06 个基点（π̂ 的 100.3%）。模型中公开信号的截面 SD 约为 0.67，按截面 SD 计，λ* 约合 17 个基点。
4. **v2 的八个主要问题都 supported，但“转移”类效应远小于 H3。** 小企业在全部漂绿决策中的份额，V − B 为 +0.34 个百分点（H3 为 +24.3）；受鉴证企业的漂绿决策中最宽松方客户的份额，ALL_F16 − ALL_R16 为 +16.4 个百分点（H3 为 +69.8）；大企业的份额，F − B 为 +0.32 个百分点（H3 为 +3.7）。原因是 λ* 下 B 世界 93.5% 的决策都是漂绿（H3 为 22.9%），三个规模组的组内漂绿率都在 92.7%–95.0%，份额几乎等于各组在全部决策中的固定占比（10%、30%、60%），没有移动的余地。真实变化口径中，P1（I − F，+0.011 SD）与 P7（ALL_F16 − ALL_R16，−0.139 SD）比 H3 大，P2、P4、P6 比 H3 小。
5. **v2 的自然动态没有通过方案 A 下的持续性复核。** λ* 下评级秩相关的滞后 1、12 期为 0.674、0.052，数据为 0.929、0.548。与 λ₀ 的逐种子配对差为 −0.252 到 −0.506，绝对值是数据 95% 半宽的 29–104 倍，按第 26.22 条 (b) 事先写定的规则判为实质偏离。
6. **v3 在 λ* 下重新估计自然动态，按第 26.24 条 (e) 停止。** F0 可行；网格中三种形式都不拟合，按第 25.6 条选 T 最小的 U（δ = 0.151）。最终阶段 T = 497（H2 在 λ = 0 下选中的 Q 为 38.7），五个滞后的差都大于 H2，其中四个还超出 95% 带宽；恢复检验未恢复。v3 的确认性运行没有进行。
7. **根本原因：λ* 下多数企业的评级挤到量表顶端。** U(0.151) 下最后一期公开信号的中位数为 2.15（报告上限 2.576；λ = 0 时中位数为 0.37），一半企业落在宽 0.11 的区间内。评级不再在企业之间区分，秩相关对微小的测量误差极其敏感。在本模型中，每单位信号约 26 个基点的直接利率反应与华证评级的持续性不相容。
8. **所以论文的主要估计仍是 H3（λ = 0）；v2 作为阶段 I 的结果与 H3 并列报告。** 在 λ 的五个点上，八项对比的 40 个未校正区间都不含 0，方向都与预测相同；但量级随 λ 大幅改变，H3 的量级不能外推到融资激励与本样本一致的情形。

## 2. v1：只调利差为什么失败（第 26.19 条）

- **原规则（第 26.7 条）。** 只调利差 s（`financing_spread`），使政策前 ρ 的中位数等于 π̂。校准网格上 ρ 几乎与 s 成正比，ρ/s 为 44–46 个基点（第 26.16 条）。插值得 s* = 0.6057，是现行 0.05 的 12 倍；在校准种子上验证，ρ 的中位数为 27.95 个基点。
- **开发运行**（种子 38101–38102，106 个运行）：s₀ = 0.05 的 16 个全部完成；s_lo 完成 8 个、失败 8 个；s* 完成 5 个、失败 37 个；s_28 完成 2 个、失败 14 个；s_hi 16 个全部失败。75 个失败中 74 个为“financing adjustment exhausts the value anchor”（第 2,073–3,490 日），1 个为价格与内在价值发散。
- **机制。** 融资暴露 E 固定为初始市值的一半，合同利率 r_f + s·E/(E+P) 随价格下跌而上升。s* 下初始合同利率已是 22.7%（s₀ 下为 4.2%）。失败日价格跌到初始值 0.18% 的企业，利率为 59.6%，内在价值被每日的融资调整扣成负数。只调 s 同时放大了利率水平与利率对价格的斜率；校准只跑政策前 1200 日，没有暴露这一点。
- **可运行的范围**（只看 B 场景、两个开发种子）：s ≤ 0.3 都完成 3500 日，对应 ρ ≈ 13.7 个基点；s = 0.4 时一个种子失败。
- **处理。** 约九成运行失败时 P1–P8 无法回答，所以不冻结、不启动，换算规则交用户修订。

## 3. 方案 A 与 λ 的校准（第 26.20–26.21 条）

- **设计。** 用户选定方案 A：保持利率水平，另加债务利率对评级的直接反应。报价利率改为 r_i = r_f + s·E_i/(E_i + P_i) − λ·(z_i − z̄)，s 保持 0.05；z_i 是报价时投资者已看到的最新公开信号，z̄ 是同日 200 家企业的等权截面均值。企业每 SD 的年融资节约为 B = (E/P)·(ρ_price + λ)，自身效应取 λ（不取 λ(1 − 1/N)）。
- **源码与测试。** `config.py` 新增 `financing_rating_slope`（默认 0），`game.py` 改报价、初始利率的报价时点与 `marginal_financing_saving`。λ = 0 时结果逐位不变：8 个开发档案运行的指纹与档案相同。全量测试 1,022 项通过；第 26.23 条补充有限差分测试后为 1,023 项。
- **校准**（种子 56001–56003，政策前 1200 日，[calibration_target_v2.json](calibration_target_v2.json)）：λ 初值 = π̂ − median ρ_price(s₀) = 27.959 − 2.212，取四位有效数字为 **λ* = 25.75 个基点**。验证：ρ_total 的中位数为 28.06 个基点（各种子 27.99、27.94、28.38），是 π̂ 的 100.3%，不需要调整。
- **敏感性点**（同一平移规则）：λ₀ = 0（现行模型）；λ_lo = 21.20（ρ_total 中位数 23.51，目标 23.41）；λ_hi = 30.30（32.61，目标 32.51）；λ_FE = 9.675（11.95，目标为加公司固定效应的 11.89）。λ_FE 是看到 E1 的稳健性结果之后新增的探索性点。
- **λ* 下的诊断。** ρ_price 中位数 2.31 个基点（λ = 0 时 2.21）；B 的中位数为市值的 13.8 个基点；决策日合同利率 3.13%–6.07%，中位数 4.15%；初始利率 3.49%–4.96%（λ = 0 时所有企业都是 4.17%）；股息率斜率 −19.1 个基点；价格截断 1 次（种子 56003，与第 26.16 条是同一家企业）。
- **两种“1 SD”口径。** π̂ 的单位是秩正态得分的 1 个截面 SD；模型按第 14 节以信号的 1 个单位记 1 SD。λ* 下决策日公开信号的截面 SD 中位数为 0.67（范围 0.52–0.99，0.99 为第 0 日）。按截面 SD 计，λ* 约合每 SD 17 个基点。按第 26.20 条 (d)，这一项只作诊断，不作调整依据；怎样对应两种口径，第 26.22 条 (f) 第 1 项留待另行决定，至今没有决定。
- **开发运行**（`check_v2`，106 个运行）：全部完成 3500 日，没有失败的尝试，没有价格截断，第 26.20 条 (f) 的停止条件没有触发。

## 10. 诊断：λ* 下公开信号挤到量表顶端（第 26.25 条，描述）

估计中发现，U(0.151) 下测量误差 σ_m 从 0 变为 0.008，滞后 1 的矩就从 0.954 降到 0.945；σ_m = 0.05 时降到 0.768。λ = 0 时同样的 σ_m 几乎不改变矩（0.925、0.925、0.922）。原因在信号的截面分布（[signal_bunching.md](signal_bunching.md)，只读 B 世界的抽样信号，各档案取前 10 个种子，F0 为 5 个）：

|---|---:|---|---|---:|---:|
| H2 最终阶段 | 0 | Q(0.505, 0.423) | −0.95 / −0.31 / 0.37 / 1.12 / 1.85 / 2.58 | 1.04 | 4.5 |
| F0 | 25.75 | Q(0.505, 0.423) | 0.90 / 1.50 / 1.94 / 2.17 / 2.29 / 2.58 | 0.60 | 11.2 |
| F0 | 25.75 | U(0) | 1.27 / 2.21 / 2.31 / 2.36 / 2.41 / 2.58 | 0.53 | 81.7 |
| v3 最终阶段 | 25.75 | U(0.151) | 0.70 / 2.08 / 2.15 / 2.20 / 2.24 / 2.35 | 0.74 | 98.2 |

“最大聚集组”为每期按信号排序后、相邻差都小于 0.005 的最大一组企业数，对各期取平均。

- λ* 下多数企业的公开信号被推到量表顶端附近（2.576 是报告上限，对应满分）。U(0.151) 下一半企业（p25 到 p75）落在 2.08–2.20 之间，宽 0.11；λ = 0 时这一段宽 1.43。平均约 98 家企业连成一个相邻差都小于 0.005 的组，组内排序几乎只由微小差异决定。
- 所以 λ* 下的秩相关一方面很低（Q 下），一方面对微小的测量误差极其敏感（U 下）。持续性偏离与 v3 的停止都由此而来。
- 结论：在本模型中，每单位信号约 26 个基点的直接利率反应使多数企业把评级推到顶端，评级不再在企业之间区分。这比“持续性偏离”更根本：在现有的行动技术（每期上限 0.25 SD、报告上限、成本设定）下，这一融资激励与华证评级的截面分布和持续性不相容。

## 11. 表述范围与限制

- **阶段 I 的结果以 v2 为准**，标为“事先登记、但自然动态未通过方案 A 下持续性复核的版本”（第 26.24 条 (h)）。论文的主要估计仍是 H3（λ = 0）；v2 与 H3 并列报告，不替代 H3。
- **不相容是模型内的结论。** 它说的是：在本模型的行动技术与报告上限下，让融资激励对准本样本的估计会使评级挤到顶端。它不说明真实企业的融资溢价不存在，也不说明真实评级的持续性与融资溢价矛盾。第 26.24 条 (c) 列出的方向（放开 λ 与自然动态一起拟合两个目标，在阶段 K 中重估行动成本）都没有做。
- **π̂ 是关联，不是因果效应。** 加公司固定效应后为 11.9 个基点；模型的 ρ 是企业自身信号变化引起的利率变化，更接近公司内的口径。λ_FE = 9.675 下，持续性同样是实质偏离（滞后 1 为 0.780），B 世界 85.8% 的决策是漂绿。所以改用公司内的估计也不能消除不相容。
- **两种“1 SD”口径**没有处理：按截面 SD 计，λ* 约合 17 个基点（第 3 节）。
- **直接通道是约化形式的假设**：贷款人按公开评级定价，与股价无关；不区分评级的信息含义与绿色信贷等政策优惠。它是相对评级定价：每个报价日直接项的**等权**截面均值为 0，但按融资暴露加权的平均一般不为 0，实际平均利率的路径也随 λ 改变（第 26.22 条 (e)）。固定参照均值的对照没有做（第 26.22 条 (f) 第 2 项）。
- **零偏好负对照只在 λ = 0 时成立。** 阶段 F 的“股票投资者没有 ESG 偏好时，企业不行动”是旧机制的结论。λ > 0 时，即使偏好为 0，B = (E/P)·(ρ_price + λ) > 0，企业仍有行动激励；在方案 A 下，企业的融资激励不依赖股票投资者的偏好。λ* 下的零偏好运行没有做（第 26.22 条 (f) 第 2 项）。
- **H2 的结论不变**：Q 被数据拒绝，恢复检验未恢复。v3 中选出的 U(0.151) 同样被拒绝、未恢复。
- **28 个基点的权益成本目标**仍只是偏好强度的校准目标，本阶段没有样本内的权益成本估计，留给阶段 J。
- 论文与仓库 README 的对外文字没有改动，修改稿待用户确认。
