# 华证 ESG 评级历史面板（2009–2022）：质量检查与评级动态

> **2026-10-26 更正**：本报告所用的转存文件有 6 个季度（标为 2021-06 至 2022-09）与新下载的 2009-01 至 2025-10 季度面板不一致，季度标签也晚两个月；本页数字含这些问题，已由 [huazheng_panel_dynamics_20261026](../huazheng_panel_dynamics_20261026/README.md) 取代。

**数据来源**：用户提供的百度网盘文件，标注“数据来源：Wind 数据库”，经“数据皮皮侠”公众号转存。**未与 Wind 或 CSMAR 官方数据核对**。原始文件放在 `data/raw/huazheng_panel_netdisk_20261013/`，不提交到仓库；本目录只有处理脚本 [analyze.py](analyze.py) 和汇总统计 [summary.json](summary.json)。同时提供的 `数据总览.xlsx` 是公众号的数据目录和推广说明，不含研究数据，未使用。

## 质量检查

- 5,075 家公司，代码不重复；季度评级覆盖 2009Q1–2022Q4 共 56 个季度；有评级的公司从 2009 年的 1,565 家增至 2022 年的 4,974 家。
- 年末评级与第四季度评级：42,184 个对比全部一致。
- “季度平均”数值表与字母评级按 C=1 … AAA=9 换算：163,589 个对比全部一致；但其中 37 个公司简称被改坏（例如“万科A”变成“万科7”），说明整理者用文本替换生成了数值表。本分析只使用字母评级表。
- 缺失值有两种写法：0（117,043 个）和空白（3,568 个），都按缺失处理。

## 评级水平：与其他来源对不上

| 来源 | 平均评级（1–9） |
|---|---|
| 本面板，全 A 股公司季度，2009–2022 | 4.10（约 B）；AAA 0 个，AA 29 个 |
| 赵阳、曾文锐、荆中博（2024），A 股 2009–2020 | 6.779 |
| 本项目 2026-09-24 沪深 300 快照 | 约 7，以 A、AA、AAA 为主 |

可能的原因：大公司评级普遍更高；华证在 2023 年前后的方法升级改变了评级水平；论文的赋值方式不同（该文的两处表述分别写 C 或 CCC 为 1）；或者转存数据有误。**在核实之前，不把本面板的评级水平与 2026 年快照拼接。**

## 评级动态（同一方法内部）

| 统计 | 结果 |
|---|---|
| 季度间评级变化概率 | 23.3%（升 11.8%，降 11.5%） |
| 变化幅度 | 1 档 33,449 次，2 档 3,211 次，3 档及以上 375 次 |
| 平均季度变化 | −0.004 档（标准差 0.56） |
| 各年平均水平 | 3.94–4.32，没有趋势 |
| 自相关 | 相隔 1 个季度 0.88，相隔 4 个季度 0.69 |
| 按当前评级的下季度平均变化 | C +0.30，CC +0.24，CCC +0.13，B +0.02，BB −0.10，BBB −0.26，A −0.48 |

## 对模型的含义（待研究决定）

1. **衰减的形式。** 模型假设所有企业每年统一向下衰减 0.2 SD；数据显示的是向中间水平回归，整体没有趋势。均值回归的一部分可能来自评级的测量噪声，本面板无法区分。
2. **评级可能是相对打分。** 14 年间全 A 股的平均评级没有上升。如果华证评级是在同类企业之间相对打分的，那么“全市场整体改善”无法从评级中观察到，而模型的政策主指标正是平均的真实改善。需要查华证评级方法确认。
3. **核实优先。** 用 CSMAR 或 Wind 导出官方华证评级的一个样本（例如 2020 年第四季度的全部公司），与本面板逐条对比，既能验证这份转存数据，也能判断上表的水平差异来自哪里。
