# 阶段 K：执法强度、漂绿代理与企业成本参数

设计见[研究契约第 28 节](../../docs/disclosure_research_contract.md)（2026-10-29 用户批准）。本目录的原始数据与面板只留本地（`data/processed/stage_k_20261029/`），这里只放脚本与汇总结果。

## K1：信息披露违规的执法强度（2026-10-29）

`k1_build.py` 识别事件并写出总体，`k1_estimate.py --final` 只运行了一次（HEAD `137e09c`），结果在 [k1_estimates.json](k1_estimates.json)。实施细节与一次错误的检查运行见契约第 28.13 条。

**数据与定义。** CNRDS 上市公司违规与处罚表。事件：对象为公司本身，由证监会系统或沪深交易所处理，违规行为文本含披露类关键词（第 28.2 条）。层级：T1 行政处罚（罚款、警告、没收），T2 纪律处分（公开谴责、通报批评、公开批评），T3 监管措施（警示函、监管关注、责令改正等）。总体为沪深 A 股非金融公司，当年至少 6 个月有月回报率。主期间 2016–2025 年，40,435 个公司-年。区间为按公司的自助法 95% 区间（1,000 次，种子 28901）。

**结果。**

| 量 | 估计 |
|---|---|
| 每年被处罚或处分（T1∪T2）的公司-年比例 | 3.53% [3.29, 3.78] |
| 其中行政处罚（T1） | 1.17% [1.06, 1.29] |
| 含监管措施（T1∪T2∪T3） | 10.84% [10.40, 11.30] |
| T1∪T2，大 / 中 / 小企业（上一年末市值前 10%、其后 30%、其余 60%） | 1.06% / 2.48% / 4.57% |
| 小企业与大企业之比（T1∪T2） | 4.30，ln 比值 1.46 [1.09, 1.91] |
| 2020-03 以后行政处罚对公司的罚款：均值，中位数 | 512 万元，250 万元（481 个事件） |
| 此前：均值，中位数 | 70 万元，50 万元（112 个事件） |
| 每个处罚或处分事件的平均罚款 F_K（2020-03 至 2025-12，纪律处分计 0） | 180.9 万元 [135.7, 245.2] |
| 有事件的公司-年中，最高层级为 T1 / T2 / T3 | 10.8% / 21.7% / 67.5% |
| 文本涉及 ESG 或环境信息披露的事件 | 10 个，都没有罚款 |

**怎么读。**

- 这些是一般信息披露违规被处罚的频率与金额，不是 ESG 报告的核查概率。观察到的发生率混合了违规的普遍程度、检查与发现的概率和处罚决定，只是“违规公司中每年被发现的比例”的下界（审稿意见 E3）。ESG 专项几乎没有处罚记录。
- 模型主设定中每年被核查的概率为 4.1%（每 60 个交易日 1%）。这一参数保持不变，在 K3 中给出部分识别的范围。
- 小企业被处罚的频率约为大企业的 4 倍，按十分位单调下降。这既可能是小企业违规更多，也可能是监管更常检查小企业，数据不能区分两者。
- 模型主设定的罚款按法定上限 1000 万元设定；本样本每个处罚或处分事件的平均罚款约为它的 18%。按契约第 28.12 条，K3 改用 180.9 万元。
- 处罚以公告日计，违规期间不详；2016 年前后覆盖不同，不直接比较。
