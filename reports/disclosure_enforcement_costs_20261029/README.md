## K1：信息披露违规的执法强度（2026-10-29）

`k1_build.py` 识别事件并写出总体，`k1_estimate.py --final` 只运行了一次（HEAD `137e09c`），结果在 [k1_estimates.json](k1_estimates.json)。实施细节与一次错误的检查运行见契约第 28.13 条。`--final` 的规模组误按包括金融公司在内的全部 A 股排序，按规模的数字以 [k1_size_correction.json](k1_size_correction.json) 为准（契约第 28.15 条）。

**数据与定义。** CNRDS 上市公司违规与处罚表。事件：对象为公司本身，由证监会系统或沪深交易所处理，违规行为文本含披露类关键词（第 28.2 条）。层级：T1 行政处罚（罚款、警告、没收），T2 纪律处分（公开谴责、通报批评、公开批评），T3 监管措施（警示函、监管关注、责令改正等）。总体为沪深 A 股非金融公司，当年至少 6 个月有月回报率。主期间 2016–2025 年，40,435 个公司-年。区间为按公司的自助法 95% 区间（1,000 次，种子 28901）。

**结果。**

**怎么读。**

- 这些是一般信息披露违规被处罚的频率与金额，不是 ESG 报告的核查概率。观察到的发生率混合了违规的普遍程度、检查与发现的概率和处罚决定，只是“违规公司中每年被发现的比例”的下界（审稿意见 E3）。ESG 专项几乎没有处罚记录。
- 模型主设定中每年被核查的概率为 4.1%（每 60 个交易日 1%）。这一参数保持不变，在 K3 中给出部分识别的范围。
- 小企业被处罚的频率约为大企业的 4 倍（3.97），按十分位单调下降。这既可能是小企业违规更多，也可能是监管更常检查小企业，数据不能区分两者。
- 模型主设定的罚款按法定上限 1000 万元设定；本样本每个处罚或处分事件的平均罚款约为它的 18%。按契约第 28.12 条，K3 改用 180.9 万元。
- 处罚以公告日计，违规期间不详；2016 年前后覆盖不同，不直接比较。

### 估计过程

- **(a) 全局设计。** 在五个可识别参数的范围内取 160 个打乱的 Sobol 点，J = g′Wg 最小的点为 s1_137，J = 1,190；J 有限的 155 个点上，J 的中位数为 26,688。
- **(b) 局部设计。** 以 s1_137 为中心、各维 ±15% 范围宽度的框内取 80 个点，每个矩拟合二次代理面（σ_m 方向用三次样条），在框内求 J 的最小值。第一次局部估计为 κ_T 0.113、s_P 0.734、η 1.665、ψ 0.817、w 0.050，代理面上 J = 595。s_P 落在框的边界上，按规则以它为中心重做一次，得到 θ̂，代理面上 J = 625。θ̂ 仍在新框的边界上（s_P 在下边界，η、ψ 在上边界），按规则记为“在局部框的边界上”，不再移动。两次代理面的交叉验证都合格：误差与模拟标准差之比最大为 1.44 和 1.15，门槛为 1.5。
- **两次代理面不一致。** 在第一次局部估计的位置上，第一次的代理面给出 J = 595，重新居中后的代理面给出 748，离这一点最近的新设计点实测 J = 2,707。J 在这一带很陡，二次代理面对 J 的误差可达几百。交叉验证衡量的是相对于模拟噪声的误差，而 J 按数据标准误加权，所以检查合格并不保证 J 准确。

**怎么读。**

- 拒绝来自多处，不集中在某一个矩：评级的持续性（模型的一期秩相关偏低，二至十二个季度偏高）、评级变动（模型中改变档位的公司更多，变化 2 档以上的更少）、评级的规模梯度（m8：模型 0.625，数据 0.873），以及查处的规模梯度（m9 方向相反，见下节）。
- 三明治区间只含抽样误差。模型被拒绝时这些区间偏窄，只能读作“在这一模型之内”的精度。
- 点估计依赖权重矩阵。剖面区间用 Ω⁻¹（含非对角元）加权，五个参数中有四个的剖面区间不含 θ̂；J* 在局部框内的最小点约为 κ_T 0.219、s_P 0.763、η 1.215、ψ 1.027、w 0.162，与对角加权的 θ̂ 不同。所以剖面区间照实报告，但不能当作 θ̂ 的置信区间。
- 两次局部估计（第二次即 θ̂）之间，比较一致的只有两点：w 都在 0.050–0.060（范围下端附近），κ_T 都在 0.100–0.113（范围下端附近）。
- 论文若报告这些估计，须同时写明：拟合检验拒绝；c 识别不了，s_P 识别弱；κ_T 未恢复；θ̂ 在局部框的边界上；点估计依赖权重矩阵与代理面。

### 查处的规模梯度（m9）

- **数据：** 小企业每年被处罚或处分的比例约为大企业的 3.97 倍（ln 比值 1.378 [1.05, 1.78]）。**θ̂ 处的模型：** 小企业 2.54%、大企业 3.94%（ln 比值 −0.438）。
- **已测试的点：** [m9_tally_k3.py](m9_tally_k3.py) 汇总 K3 的 7 个估计档案，共 359 个不同的参数点（最终阶段与恢复检验是同一个 θ̂，计算 360 次）：354 次为负，最大 −0.155；5 次为 −∞（小企业组没有查处）；1 次两组都没有查处（(q, w) = (0.04, 0.8)）；没有一次为正或为 0。这些点包括在五个可识别参数整个范围内取的 160 个全局设计点（c 固定）、c 的差分点，以及 θ̂ 上 q ∈ [0.0025, 0.04] 与 w ∈ [0.05, 0.8] 的网格；其余固定参数从未变动。所以只能说**在所有已测试的参数点上，模型都没有出现与数据同方向的梯度**；有限个点不能证明连续参数空间中不存在例外，其余固定参数下的情况也没有测试。
- **模型中虚报的分布：** 核查概率在企业之间相同时，查处比只反映各组虚报的普遍程度（第 28.4 条）。在 θ̂（q = 0.010，种子 69001–69030）下，虚报中的企业-日占比大企业为 0.931，小企业为 0.610。
- **原因没有分解。** 模型一侧，定额罚款按企业价格折算（F / P），对小企业的相对威慑更大；成本设定（ψ、η）也会影响各组的选择，K3 没有把这些因素分开。数据一侧，处罚记录同时受违规发生、核查、发现、处分与记录覆盖的影响；G2 不通过，没有独立的漂绿代理把它们分开；一般信息披露违规与模型中的 ESG 虚报如何对应，也没有验证。所以 m9 方向相反，并不能确定应当修改模型的哪一环。
- **统一提高 q 没有改善 m9。** 在固定 ŵ 的 q 扫描中，q 由 0.010 增至 0.020，m9 由 −0.457 降至 −0.668。总体上随 q 更负，但不单调：q 由 0.014 增至 0.015 时，m9 由 −0.582 回到 −0.571。
- **规模相关的核查概率只是候选机制之一**（第 28.32 条 (6)），与定额罚款的相对威慑、成本设定、数据中违规发生与记录覆盖的规模差异并列。若要检验，须固定总体核查预算，写明企业是否知道差异化的规则，并重新检查识别、恢复与全部 m1–m9。
- **分组口径。** 数据一侧（K1 与 m9）在非金融总体内按上一年末总市值每年重新分组；模型按初始价值固定分组；m8 在每个观测日有评级的全部 A 股（含金融公司）内按当月末市值分组。解释 m9 时须同时说明这些差异。

- 对照为 K1 主口径 T1∪T2 的年发生率 3.53% [3.29, 3.78]。均值落在这一区间内的网格点只有 (0.02, 0.2)。这是按事先写定的规则得到的唯一网格点，不表示在统计上排除了其他点：在区间两侧的点（q = 0.01、0.02，w ≤ 0.2），5 个种子的标准误为 0.35–0.49 个百分点（全表 0–0.88）；(0.02, 0.2) 的 t 区间约为 [2.32%, 5.03%]。
- 表格的读法：w = 0.05、0.1、0.2 三列随 q 上升，w = 0.4、0.8 两列不单调；每个 q 下，查处率在五个已测试的 w 点上依次下降。

- **ESG 专项的处罚记录：** 2016–2025 年只有 2 个 T1∪T2 事件，分母 40,435 个公司-年，单侧 95% 上限 0.0156%。网格上只有 (0.04, 0.8) 不超过这一上限，即模型中没有任何查处的点。ESG 专项记录只是下界，所以这说明处罚记录约束不了 ESG 的核查概率，并不说明实际的 ESG 执法如此之少。

- **结论（按事先写定的句式）：** θ̂ 的其余参数不变时，在已测试的 q ∈ [0.010, 0.020] 中，q = 0.011–0.014 使模型的年查处率不能排除与 K1 主口径相容，对应每年被核查的概率为 4.54%–5.75%（主设定 q = 0.010 为 4.13%）；按点值规则为 q = 0.012、0.013。
- 10 个相邻步上，查处率的均值都上升。线性插值只作描述：均值在 q ≈ 0.0112 处穿过 3.29%，在 q ≈ 0.0134 处穿过 3.78%。

- 复核：q = 0.010 的扫描均值 3.05%，与最终阶段（另一组种子）的 3.00% 相差 0.05 个百分点，合并标准误 0.13。
- **读法：** 这只回答“如果 ESG 报告的执法强度与一般信息披露相同，在这一 θ̂ 下 q 要多大”。K1 的发生率是一般信息披露违规年发现概率的下界；θ̂ 被拒绝；q 改变后 θ̂ 本身也可能改变，本节没有重估。所以这不是对 ESG 核查概率的估计，主设定的 q 不变。
- **附带结果（只作描述）：** q 由 0.010 增至 0.020 时，虚报中的企业-日占比由 0.709 降至 0.586（大企业 0.931 → 0.878，小企业 0.610 → 0.464）；核查中查出虚报的比例由 0.720 降至 0.597。全体企业的这两项占比在 11 个已测试的 q 上逐点下降。模型中被查处即清零，所以占比下降既可能来自新虚报减少，也可能来自更频繁的清零，这里没有把两者分开。J 在 q = 0.011 处最低（730），q = 0.010 处为 754；同一参数在最终阶段（另一组种子）为 808.5，所以 q = 0.010–0.013 之间 J 的差别在种子变化的量级内，不据此比较这几个 q。
