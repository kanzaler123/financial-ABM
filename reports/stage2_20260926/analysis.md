## 时序与信息边界

第 1、21、41…日，交易者以截至前一日收盘的主观估值偏离、动量、波动、自身回撤
选择动作，持有 20 日。第 1、61、121…日企业选择行动，持有 60 日。
动作选择之后才生成当日公司消息并推进信息图，随后规则策略下单、统一结算、记录奖励。
第 20/60 日结算后的更新只影响下一个完整决策窗口。

交易者只收到已经到达的公开消息、过去价格、自身状态；不把研究界面的真实公司表现
或全局真实基本面送入规则策略。企业只用自身融资、披露差距、核验风险和现金状态。
做市商处理当日已经公开的公告，不读取潜在公司真实水平；公告对公共价格的影响也会
通过后续可观察价格间接传给未收到详细消息的投资者。

图以首次到达为准，同一到达时间优先较高累计可信度，余下按路径和 ID 确定顺序。
每条边乘以 `trust × weight`；消息保留原始来源与全路径。范围限制适用于每一传播跳。
动态边权使用过去 20 日已执行订单向量的余弦相似度，次日生效，已经在途的消息保留原定
到达时间和累计信任。图为合成披露/互动网络，没有用 13F 充当社交或信任关系。

## 学习与奖励

四个状态变量各分三档，编码为 `27*b0 + 9*b1 + 3*b2 + b3`，阈值保存在审计文件中。
交易者按原始 value/trend/noise 类型共享 `3 × 81 × 4` 个 Bandit 均值与计数；
类型、风险厌恶和通用因子偏好保持不变。均值按观测次数更新，epsilon-greedy 处理探索，
并列最优均匀分配概率。逆向策略反转趋势信号，减仓行动以当前实际仓位向零调整，
避免上一个策略的未执行目标使减仓行动反而增加敞口。

设窗口初末净财富为 W0、W1，费用为 C：

`reward = (W1 + C - W0)/W0 - C/W0 - risk_penalty*risk_aversion*std(gross_daily_returns) - drawdown_penalty*max_drawdown`。

因此费用恰好扣一次。自身回撤和波动都只使用已结算的窗口信息。

企业按 3 个规模组共享 `3 × 81 × 3` 的 Q 表。各公司按 ID 固定顺序更新，同一批次的
下一状态最大 Q 在任何更新前冻结。更新式为 `Q += alpha*(r + gamma*max(Q_next) - Q)`。
动作接口是“真实投入、披露投入、维持”，没有锁定为 ESG。

企业价值代理量定义为 `初始资产 × 真实生产表现 × 市场价格/初始价格`，不含现金，
奖励再单独列出真实投入费用、披露费用和核验罚金，以免重复扣费；融资项是相对窗口开始
利率维持 60 日的利息节约。五项均按初始资产归一化。该奖励是明确的合成效用，不是
企业总财富收益率，也不表示企业在现实市场有同样激励。

真实投入增加生产资本，资本逐日折旧；披露投入增加报告信号，核验可能揭示差距并罚款。
核验前的消息信誉只使用上一次已公开的核验历史，避免通过信誉分数泄漏当前私有差距。
运营收入、利息、投入和罚金通过企业外部现金账户逐项对记，和交易市场做市商账本分开。

```powershell
.\.venv\Scripts\python.exe -m abm.runner --config configs/stage2.json --output runs/my_stage2_new
.\.venv\Scripts\python.exe -m abm.desktop --mode replay --run-dir runs/stage2_five_nodes_20260926

```

`source_snapshot.zip` 保存本次源码、配置、夹具、测试和 Web 源文件；哈希见
`verification.json`。Manifest 也记录每个 Python 文件的内容哈希，因此后续代码变更会产生新身份。
一阶段历史正式实验使用自己的 `frozen_stage1_source.zip`，不覆盖旧失败结论或解除旧清单保护。
小人口关闭二阶段并启用旧 Logit 时，空策略适应度原为负无穷，导致 JSON 不能保存；
本次仅将日志中的该缺失值输出为 null，实际学习概率与有限值路径保持不变。

实时 UI 和持久化均消费同一日频事件；UI 不写回市场状态。逐日日志在显示发送前 flush/fsync。
日志支持中断后读取已完成日期，不承诺从中间状态继续训练。偏好字段本阶段保持稳定但不进入
金融奖励，真实事件、因子含义、真实数据拟合、多资产和 PPO 属于后续阶段。
