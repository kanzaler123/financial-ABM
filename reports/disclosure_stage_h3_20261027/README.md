# 阶段 H3：在评级持续性估计值下确认性重跑论文的主要结论（2026-10-27）

**性质：确认性实验。** 设计、种子、八个主要问题、判定规则和解析预测在实现与运行之前写入[契约第 25 节](../../docs/disclosure_research_contract.md)第 8 条并提交；实施细则、开发检查与冻结身份在确认性运行之前写入第 25.17 条并提交（`e24c7ca`）。自然动态取 H2 选出的主设定 Q 的点估计（[估计报告](../disclosure_persistence_estimation_20261026/README.md)）：`natural_decay` = 0，`natural_reversion` = κ_T = 0.505，`reversion_permanent_share` = s_P = 0.423。Q 仍被评级数据拒绝（T = 38，p < 10⁻⁶），恢复检验记“未恢复”（κ_T 偏高约 4–9%），所以本报告的结果是“在与华证评级持续性最接近、但仍被拒绝的动态下”的结果。

24 个场景 × 30 个种子（53001–53030）= 720 个世界，全部一次完成，没有失败的尝试，没有运行未通过核心验证，没有价格截断。`experiment_id` = `12fe871e…d8eb`。企业使用连续 NPV 规则。八个主要问题为双侧配对 t 检验，八项一起作 Holm 校正；其余为未校正的配对 95% t 区间。

## 结论

1. **八个主要问题都 supported，论文的六个定性结论在估计值下方向都成立，而且都可分辨。** 排序 I > F > B，定额罚款把漂绿留在大企业，按市值定向把漂绿推向小企业并拉大规模鸿沟，规则公布后的规避，挑选鉴证方的代价，漂绿流向最宽松的鉴证方。
2. **以真实变化衡量的政策效应很小，比原主设定（统一衰减 0.2 SD/年）小一到两个数量级。** I − F 为 +0.003 SD（原 +0.205），F − B 为 +0.014（原 +0.125），I − B 为 +0.017（原 +0.331），J − J_hidden 为 −0.010（原 −0.131），ALL_F16 − ALL_R16 为 −0.017（原 −0.199）。原因与第 20.21 条相同：Q 中改善按 κ_T 回落，真实改善的年金 A_r 从 3.73 降到 1.50，τ = 0.6 不再越过漂绿门槛 τ* = 0.825。
3. **以漂绿决策的去向衡量，效应仍然大。** 按市值定向使小企业在全部漂绿决策中的份额增加 24 个百分点；企业挑选鉴证方时，受鉴证企业的漂绿决策有 95.6% 来自当年质量最低的鉴证方的客户，比指派时多 70 个百分点。定额罚款使大企业的份额增加 3.7 个百分点。
4. **解析预测 T1 按事先的规则记“不成立”，但不是反转。** 主块中 F − B 的漂绿决策占比为 −4.6 个百分点，区间在 0 以下；I − F 为 +0.02 个百分点 [−0.06, +0.10]，区间含 0，在本设计下不能分辨 I 与 F 的漂绿占比（两者都约 18.3%）。
5. **改善持久时（perm_ 块）政策效应明显更大**：I − F +0.077，F − B +0.021，I − B +0.097 SD；这时 τ* = 0.565 < 0.6，I 中没有漂绿决策。H3 的量级因此主要取决于“改善是否像冲击一样回落”这一假设，而数据不能识别这一点（契约第 25.13 条）。
6. **参照块在新种子上复现了原主设定**：u0p2_ 块 I − F +0.193、F − B +0.148、I − B +0.341（阶段 F 为 +0.205、+0.125、+0.331）。

## 4. 辅助分析（未校正）

**定向核查与同预算的随机核查：** V − A2 −0.031 [−0.036, −0.026]，J − A2 −0.020 [−0.023, −0.016] SD；方向与第 21 节相同（企业知道规则时，两种定向都不如同预算的随机核查）。

**边际威慑：** F − F_2x +0.005 [+0.003, +0.006]，F_8x − F +0.002 [+0.001, +0.003] SD；漂绿决策占比 F_2x、F、F_8x 依次为 19.6%、18.3%、17.8%。罚款加倍再加倍，效应递减。

**改善持久（perm_）：** I − F +0.077 [+0.066, +0.088]，F − B +0.021 [+0.015, +0.026]，I − B +0.097 [+0.082, +0.112]；市值加权口径为 +0.158、+0.029、+0.187。

**参照块（原主设定，新种子）：** I − F +0.193 [+0.167, +0.219]，F − B +0.148 [+0.126, +0.170]，I − B +0.341 [+0.305, +0.377]。主块与参照块的配对差（如 B − u0p2_B +1.21 SD）主要反映有无统一衰减，即真实水平是否整体下滑，不是政策效应，这里不作解读。

**描述：** B 中大企业的漂绿率为 73.4%（参照块 64.5%，论文摘要的“三分之二”用的是原主设定）。各场景的漂绿决策中 89–100% 是继续已有案件（企业已持有未被查出的虚报）。全部场景的 30 个种子都有漂绿决策，只有 u0p2_I 与 perm_I 例外：这两个场景中 τ = 0.6 高于 τ* = 0.565，30 个种子都没有漂绿决策。完整表格见 [h3_v1_tables.md](h3_v1_tables.md)。

## 6. 表述范围

- 结果对应的是与华证综合得分持续性最接近、但仍被数据拒绝的 Q；κ_T 的识别较弱，恢复检验中估计偏高约 4–9%。
- Q 中改善按暂时成分回落是假设；perm_ 块表明这一假设决定了量级。对外应把 H3 的主块与 perm_ 块并列报告，不单引其中一个。
- 判定为 supported 只说明方向成立且可分辨。真实变化口径的效应只有 0.003–0.017 SD，不能写成“效应稳健”或“量级不变”。
- 论文与仓库 README 的对外文字没有改动，修改稿待用户确认。
