## 主要发现

**漂绿会流向执法最弱的地方。** 这是[论文](paper/main.pdf)的主要结论，来自事先登记设计的实验，以模型假设为条件。来源：阶段 F（1770 个模拟市场）、阶段 E.1（450 个）与 E.2（540 个），以及联合稳健性检验（720 个）。下面每一处执法缺口，都是漂绿流向的地方：

- **流向大企业：罚款有上限时（阶段 F）。** 定额罚款取《证券法》对虚假披露的罚款上限（每案 1000 万元，第 197 条第二款），作为基准，不判断它是否适用于 ESG 报告；此时大企业 66% 的决策是漂绿，小企业为 6%。差距来自这个上限相对大市值微不足道，而不是大企业改善成本更高。
- **流向已有的未查出案件：一案只罚一次时（阶段 F）。** 从不罚款到这一罚款，漂绿决策占比从 91% 降到 22%，但罚款提高到 8 倍仍剩 12.5%，因为企业把新的虚报加到尚未查出的案件上，不会再被罚一次。改为每份虚假报告各罚一笔后，8 倍罚款下降到 0.8%。
- **流向小企业和小幅跳升：企业知道核查规则时（阶段 E.1）。** 在相同的期望核查次数下，按市值核查把漂绿从大企业挤到小企业，等权真实 ESG 水平比随机核查低 0.19 SD；按报告跳升核查低 0.14 SD，因为企业把新虚报压在跳升门槛之下。规则不公布时，两种定向规则与随机核查都未检出统计显著差异。两种规则都未经优化。
- **流向最宽松的鉴证方：企业自选鉴证方时（阶段 E.2）。** 在鉴证方责任强（16 倍）、全部企业强制鉴证时，让企业自选鉴证方抵消了随机指派带来的大部分改善（比指派低 0.20 SD）。按决策次数计，被鉴证企业的漂绿决策 96.9% 出自当年质量最低的鉴证方的客户。

另外两条结果划定了这个结论的范围：

- **透明度更难绕开，但它多带来多少改善，取决于真实改善能持续多久（阶段 F 与联合稳健性检验）。** 在测试剂量下，透明度从 0.1 提高到 0.6，比定额罚款提高到 4 倍更能提高真实水平；两者没有按成本匹配。这一排序在自然衰减两端（0 与每年 0.2 SD）、真实水平均值回归下，以及预注册联合检验的全部四个设定中都成立，但差距大小不稳健：每年 0.2 SD 衰减时为 +0.21 SD，无衰减时为 +0.035 SD，均值回归下只有 +0.003 到 +0.012 SD（两个回归速度是敏感性取值，不是估计值）。所有企业漂绿成本相同、真实改善持久时，透明度超过 ≈ 0.57 后漂绿停止；漂绿成本因企业而异时，漂绿随透明度提高逐步减少。
- **没有在乎 ESG 的投资者，政策就不起作用（阶段 F）。** 去掉影响力投资者对报告 ESG 的偏好，企业既不改善也不漂绿，所有政策都没有效果。

数值、区间和限定条件见下文[阶段 F 发现](#阶段-f-发现)、[定向核查](#定向核查阶段-e1)与[鉴证机构](#鉴证机构阶段-e2)，以及[论文](paper/main.pdf)。

> [!NOTE]
> **研究进行中。** 本页与论文报告的是主实验（阶段 F、E.1、E.2 与联合稳健性检验）。结论以模型假设为条件；量级取决于真实改善能持续多久，这些实验没有校准它，所以按区间报告。阶段 H 之后用季度评级面板估计了它，并在估计值下重跑了实验，这些结果尚未写进本页和论文正文。阶段 I（本样本的融资溢价）与阶段 J（投资者对评级的反应）见[英文 README](README.md#financing-premium-stage-i) 与论文附录（[`paper/`](paper/main.pdf) 中为 2026 年 10 月 29 日版；SSRN 上仍是 10 月 24 日版），本页尚未收录。后续阶段见[路线图](#路线图)。

## 快速开始

**不用安装：** 打开[在线政策作战台](https://kanzaler123.github.io/financial-ABM/)，拖动杠杆，再点 **复制当前政策的链接**，就能把你看到的结果原样分享出去。

**在本地跑模型**（Python 3.12+，从仓库根目录执行）：

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS / Linux: source .venv/bin/activate
python -m pip install -c requirements-lock.txt -e ".[plot,research]"
python -m abm.disclosure.experiments --spec configs/disclosure_quickstart_v1.json --output runs/quickstart --workers 2
```

运行约 10–30 秒：在 40 家企业、4 个种子的小市场上比较三种政策（基准、透明度 0.6、比例罚款）。结果在 `runs/quickstart/report.md`（带区间的配对对比）和 `policy_effects.png`。

**改一个参数，看结果怎么变。** 把 [`configs/disclosure_quickstart_v1.json`](configs/disclosure_quickstart_v1.json) 中场景 `I` 的透明度改成 `"transparency": 0.3`，换一个输出目录 `--output runs/quickstart_tau03` 再跑一次。此时透明度低于门槛：信息政策相对基准的提升从约 +0.37 SD 降到约 +0.07 SD，罚款反而更有效。快速示例使用仓库自带、未经校准的 ESG 领域和小规模市场，用来演示流程，不复现阶段 F。

开发者：`python -m pip install -c requirements-lock.txt -e ".[all,dev]"`，然后 `python -m pytest`。单资产主应用的界面和其他命令见下文[单资产主应用的本地界面](#单资产主应用的本地界面)和 [OPERATIONS.md](OPERATIONS.md)。

## 研究问题

ESG 研究大多用历史数据检验相关性：ESG 好的公司收益更高吗？融资更便宜吗？这类“向后看”的方法很难回答**转型是怎样发生的**，也无法比较现实中没有发生过的政策。

本项目换一种做法：构建一个人工金融市场，让异质的投资者和企业在其中互动、学习、演化，再把政策作为可控变量放进去，做现实中做不了的反事实实验。核心问题是：

> **在政策与市场的双轮驱动下，ESG 转型的效率和路径是怎样的？**

1. **哪种政策更有效？** 提高透明度的“信息型”政策，与提高违规成本的“惩罚型”政策，在事先固定的剂量下比较：透明度从 0.1 提高到 0.6，定额罚款从 1000 万元提高到 4 倍，另有各自的剂量梯度。两种剂量没有按期望罚金或实施成本匹配，所以比较的是这些剂量下的排序，不是同等成本下哪种政策更优。
2. **市场自身的动力有多大？** 在没有外部干预时，影响力投资者能否通过“用脚投票”自发推动转型？政策是放大还是替代了这股力量？
3. **大企业和小企业有什么不同？** ESG 规范在不同规模企业之间的传导速度，是否存在“ESG 鸿沟”？
4. **什么时候会陷入漂绿陷阱？** 在参数空间中画出相图，区分“转型成功”“转型失败”和“漂绿陷阱”。

### 博弈论视角

每一层智能体都对应一个经典博弈，可以先写出均衡基准，再用仿真检验会学习、有限理性的智能体能否到达均衡，以及在哪里偏离。

| 层面 | 博弈 | 仿真检验什么 |
|---|---|---|
| 企业与监管者 | 检查博弈 | 罚款、核查与透明度的闭式漂绿条件，加入市场反馈后是否仍然成立 |
| 企业与投资者 | 信号博弈 | “漂绿陷阱”是否就是混同均衡；透明度和鉴证能否推向分离均衡 |
| 投资者群体 | 演化博弈（复制动态） | 影响力投资的扩张来自“选择”还是“漂移” |
| 监管者 | 斯塔克伯格博弈 | 定向核查与随机核查的比较 |

## 阶段 F 发现

> 确认性实验（2026-10-15）：59 个场景 × 30 个配对种子（41001–41030），共 1770 个契约规模的世界（1000 名投资者、200 家企业、3500 个交易日）。设计、种子和主要问题在运行前写入[研究契约第 20 节](docs/disclosure_research_contract.md)并提交（`2b08f65`）。企业使用连续 NPV 规则。所有结论都以模型假设为条件。

1. **排序稳健：信息政策 > 惩罚政策 > 基准。** 这是指定剂量下的排序（透明度 0.6 对定额罚款 4 倍），两者没有按期望罚金或实施成本匹配，不能读成“同等成本下信息政策更优”。在自然衰减 0 与 0.2 SD/年两端、两个初始化对照和企业改善成本不随规模变化的“等成本”对照下都成立。阶段 F 之后补跑的探索性检验（[稳健性补充报告](reports/disclosure_robustness_20261018/README.md)）中，真实水平向均值回归、每份虚假报告各罚一笔、企业漂绿成本各不相同三种设定下排序也成立；但在均值回归下，信息政策比惩罚政策只多 +0.003 到 +0.006 SD。之后在新种子上作了预注册的确认性检验（[联合稳健性报告](reports/disclosure_joint_robustness_20261023/README.md)，契约第 24 节），让均值回归与每份虚假报告各罚一笔同时成立，并分别加上、不加企业漂绿成本各不相同：四个设定下排序都成立（经 Holm 校正的八项对比都为正），但信息政策比惩罚政策只多 +0.004 到 +0.012 SD，与只有均值回归时同一量级。
2. **量级是一个区间。** 政策窗口（第 1200–3500 日）内，信息政策使真实水平比基准高 +0.04 到 +0.33 SD，惩罚政策高 +0.005 到 +0.13 SD，信息政策比惩罚政策高 +0.035 到 +0.21 SD。两端对应不作为时每年 0 与 0.2 SD 的自然衰减。这个参数未经校准，确定它需要经过核实的评级面板（计划阶段 H）。这个区间只覆盖统一衰减：在均值回归下（两个回归速度由来源未核实的华证面板启发，是敏感性参数，不是估计值或上界），信息政策比基准高 +0.02 到 +0.03 SD，比惩罚政策高接近 0，都低于区间下端。再加上每份虚假报告各罚一笔时，信息政策比基准高 +0.04 到 +0.06 SD，比惩罚政策高 +0.004 到 +0.012 SD。下面第 3–6 条只有主设定（每年 0.2 SD）的数值，量级属区间上端。
3. **政策只能通过市场偏好起作用。** 影响力投资者的偏好使 14 年全期的真实水平提高 +0.79 SD [+0.74, +0.85]。没有偏好时，企业既不改善也不漂绿，三种政策都没有效果。
4. **透明度有门槛。** 在所有企业漂绿成本相同、真实改善持久的设定下，透明度超过 τ* ≈ 0.57 后漂绿决策完全停止，罚款也随之无关；命题 2 对门槛的预测在 16 个格点上全部成立。但切换前积累、未被查处的虚报不会自动消失。企业漂绿成本不同时，门槛是逐家的，漂绿随透明度逐步下降（τ = 0.6 时仍有 7% 的决策漂绿）；真实水平向均值回归时，门槛升到约 0.8。
5. **定额罚款的边际威慑递减。** 从 0 到 1000 万元，漂绿决策占比从 91% 降到 22%；在一案一罚的记账下，再提高到 2、4、8 倍，只降到 16%、13%、13%，因为已有未查处案件的企业，新虚报并入旧案，不面对新的定额罚款。若每份虚假报告各罚一笔，8 倍罚款下降到 0.8%，每次加倍的效果仍然递减。
6. **规模鸿沟来自漂绿，而不是成本。** 基准政策下大企业的漂绿占比为 66%，小企业为 6%，真实变化少 0.33 SD：1000 万元罚款相对大企业的市值微不足道。比例罚消除的是“大企业比小企业更倾向漂绿”的规模关系，不是漂绿本身：比例罚 1× 下大企业仍有 72% 的决策是漂绿，小企业为 88%，总体 84%。在“等额参照”下，比例罚总体远弱于定额罚（真实变化差 −0.34 SD）。

**限制。** 只研究 NPV 企业，学习型企业没有通过阶段 D 的验收，预注册重做后仍未通过（见[下文](#学习型企业阶段-d3)）；核查是固定强度的随机核查，定向核查与鉴证方见下文[阶段 E.1](#定向核查阶段-e1) 与[阶段 E.2](#鉴证机构阶段-e2)；政策的实施成本没有建模；37 个运行有价格截断，保留在统计中，剔除后结论不变。完整表格见[阶段 F 报告](reports/disclosure_stage_f_20261014/README.md)。

## 定向核查（阶段 E.1）

> 确认性实验（2026-10-20）：设计在实现与运行之前写入[研究契约第 21 节](docs/disclosure_research_contract.md)并提交（`962d1ee`）。15 个场景 × 30 个新的配对种子（42001–42030），共 450 个世界，全部完成。每种定向规则的期望核查次数都与每期 1% 的随机核查相同。企业使用连续 NPV 规则。完整表格见[阶段 E.1 报告](reports/disclosure_targeted_audits_20261020/README.md)。

- **企业知道规则时，定向核查的等权真实水平低于随机核查。** 按市值核查 −0.191 SD [−0.222, −0.159]，按报告跳升核查 −0.136 SD [−0.156, −0.116]。两种规则查出虚报的比例都高于随机核查（50% 和 69% 的核查查出虚报，随机核查为 28%）。
- **按市值核查把漂绿从大企业挤到小企业。** 大企业的漂绿占比由 64% 降到 47%，小企业由 5% 升到 35%。市值加权的真实水平上升（+0.053 SD），但小企业占企业数的六成，等权真实水平下降。
- **损害来自企业知道规则。** 规则不公布时，两种定向与随机核查都未检出统计显著差异（各 −0.005 SD，区间含 0，但这不表示等效）。公布跳升规则损失 0.131 SD：企业把新虚报压在门槛之下。
- **多查有用，换个查法没用。** 随机核查加倍使真实水平提高 +0.118 SD。信息政策仍比“按市值核查 + 4 倍罚款”高 +0.156 SD。
- 本实验的五个主要问题都是 supported（Holm p ≤ 1.1 × 10⁻¹¹）；这本身不等于上述每个机制都得到了独立验证。量级属主设定（每年 0.2 SD 衰减）；无衰减时所有效应都很小，方向不变。只比较了这两种规则，没有优化任何规则。

## 鉴证机构（阶段 E.2）

> 确认性实验（2026-10-21）：设计在实现与运行之前写入[研究契约第 22 节](docs/disclosure_research_contract.md)并提交（`307168c`）。18 个场景 × 30 个新的配对种子（43001–43030），共 540 个世界，全部完成。4 家策略型鉴证方在报告发布前检查客户的报告，查出虚报即更正；每家每年按责任作一次最优反应来设定质量，客户的虚报日后被监管者查出时由鉴证方承担责任罚款。责任剂量是 500 万元责任基准的倍数：参照《证券法》第 213 条第三款中“没有业务收入或者业务收入不足五十万元”一档的上限设置，并假定该条适用于 ESG 鉴证，本文不对适用性作判断。费用和努力成本是假设。区间是未作多重比较校正的配对 95% 区间，Holm 校正针对五个主要问题的 p 值。完整表格见[阶段 E.2 报告](reports/disclosure_assurance_20261021/README.md)。

- **强责任、指派鉴证方有效。** 16 倍责任、随机指派鉴证方时，真实水平比无鉴证高 +0.273 SD [+0.234, +0.312]，漂绿决策占比由 19.0% 降到 6.2%。
- **让企业挑选鉴证方，抵消了指派鉴证的大部分改善。** 比指派低 −0.199 SD [−0.233, −0.165]；按场景均值，仍比无鉴证高约 0.07 SD。漂绿决策占比回到 21.0%。按决策次数计，被鉴证企业的漂绿决策 96.9% 出自当年质量最低的鉴证方的客户。
- **责任基准（1 倍）下效果很小。** +0.046 SD [+0.035, +0.058]。鉴证方质量平均只有 0.014，低到相当于“罚款保险”：决策时没有未查出虚报的企业中，选择漂绿的决策比例反而高 0.9 个百分点。真实变化相对无鉴证基准仍改善，来自改善幅度变大；这一分解是事后描述，机制没有单独检验。
- **已测剂量中，16 倍改善最大，100 倍反而较低。** 相对无鉴证：1 倍 +0.046，4 倍 +0.145，10 倍 +0.256，16 倍 +0.273，100 倍 +0.232 SD；16 倍与 100 倍之间没有测试。16 倍下，28/30 个种子的年均质量先超过停止漂绿的门槛、之后又回落，30/30 个种子在最后 4 个鉴证年仍有漂绿。
- **只强制大企业时规模鸿沟缩小，但漂绿外溢到中小企业。** 大减小真实变化 +0.563 SD，等权真实变化只有 +0.057 SD。
- **信息政策仍优于已测场景中真实改善最大的鉴证设定（ALL_R16），** 差距小：+0.028 SD [+0.018, +0.038]。
- **自愿鉴证无人购买，** 因为模型中投资者只看报告分数、不奖励鉴证。这是模型假设的结果，不是预测。模型也不公开企业是否被鉴证以及鉴证报告，而上交所指引第 58 条要求聘请鉴证机构的企业披露这些信息；这一简化限制了该结果的现实解释。
- 本实验的五个主要问题都是 supported；这本身不等于上述每个机制都得到了独立验证。量级属主设定（每年 0.2 SD 衰减）；无衰减时所有效应都很小，方向不变（与第一、二、三、六条对应的对比分别为 +0.030、−0.010、+0.004、+0.009 SD）。29 个运行有价格截断，按预注册保留在主分析中，剔除后五项主要判定不变。

## 学习型企业（阶段 D.3）

> 确认性重做（2026-10-23）：设计在实现与运行之前写入[研究契约第 23 节](docs/disclosure_research_contract.md)并提交（`8bb5d9e`）。表格型 Q-learning 企业从自己的实际账目中学习：10 个独立重复 × 两个状态版本（A = D.2 的原状态；V = 把成本档位换成累计真实改善）× 四个场景（B、I、F、IF），与同一动作网格上的 NPV 企业（离散 NPV）比较。540/540 个作业完成。完整表格见[阶段 D.3 报告](reports/disclosure_learning_redo_20261021/README.md)。

- **阶段 D 的验收仍未通过。** 覆盖门槛 91/100 张表通过；未通过的 9 张都是政策后表，其中 8 张卡在大企业组。
- **训练随机性占主导。** 同一场景内，独立训练的表之间漂绿占比的差异是同一张表在验证种子之间差异的 14–18 倍，只训练一张表回答不了政策问题。
- **有漂绿陷阱，但不是学到了漂绿有利可图（P1 supported）。** 信息政策下，学习型企业的漂绿占比为 23.7%，离散 NPV 为 3.8%，差 +19.9 个百分点，Holm p = 0.031。多出的漂绿相对 NPV 选择的损失中位数约 0.042 个基点市值，远小于奖励噪声：这是“学不出来”的陷阱。其余四个主要问题（P2–P5）都是 unresolved。
- **看得见改善，漂绿减少，但没有变成改善**（辅助分析，未校正）。V 版从零训练的政策前表漂绿占比低 34.7 个百分点，但减少的漂绿变成了“维持”，真实改善没有显著增加。
- **结论脆弱，不进入主结论。** 剔除含未通过表的 5 个重复后，P1 也不显著。学习型企业不进入上文阶段 F 的主结论。

## 研究性与可复现

- **设定先于结果。** 关键设定（初始化方式、罚款含义、融资溢价目标）在运行任何政策实验之前写入[研究契约](docs/disclosure_research_contract.md)，不为得到预期的政策排序而调参。
- **失败不删除。** 机械门槛失败、中断的运行和诊断都原样保留。
- **证据可核对。** 研究证据目录按原始字节存储，报告中记录的 SHA-256 可以直接核对；重放和插桩诊断都与归档结果逐位比对。
- **参数有出处。** 每个经验参数都在[证据表](docs/disclosure_empirical_magnitudes_20261012.md)中标注来源和可信度（原文 / 摘要 / 二手）。
- **数据边界。** 华证、东方财富等供应商数据没有开放再分发许可，不放入仓库；采集脚本和 hash 清单保留，可以重新取数逐项核对。

| Stage 2 | 信息图传播、投资者 Bandit、企业表格 Q-learning；合成五节点与 1000 人试跑 |
| Stage 3 | 真实 SEC 8-K 快照、按会话截止时间进入的信息因子、归档重建、情景比较与 PNG/SVG 动画/数据导出；[验证与限制](reports/stage3_20261003/analysis.md) |
| 观察界面 | 本地 Web / 桌面 live、replay、batch；独立的 [GitHub 交互展厅](showcase/README.md) |

主应用的 Web / 桌面界面仍使用单资产市场；多资产披露研究是独立的子包 [`src/abm/disclosure`](src/abm/disclosure)。当前不提供逐笔连续限价订单簿、已校准的真实投资者社交网络、真实交易或公网仿真服务。主应用路线见[三阶段开发计划](docs/ABM三阶段开发计划_渐进式学习版.md)。
